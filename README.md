# SpreadJS 재고 관리 대시보드 (Inventory Management Dashboard)

SpreadJS를 활용하여 구현한 **재고 관리 대시보드(Inventory Management Dashboard) 샘플**입니다.

JavaScript 스프레드시트 컴포넌트인 **MESCIUS SpreadJS**를 사용하여 제품별 재고 현황과 데이터를 웹 애플리케이션에서 관리하고 확인할 수 있는 대시보드를 구현할 수 있습니다.

본 샘플에서는 재고 데이터를 스프레드시트 형태로 관리하고, 재고 현황을 시각화하여 웹 환경에서 효율적으로 확인할 수 있는 대시보드를 구성합니다.

## 주요 기능

- SpreadJS 기반 웹 스프레드시트 구현
- 제품별 재고 데이터 조회 및 관리
- 입출고 및 재고 현황 표시
- Excel과 유사한 재고 관리 화면 구성
- 수식 및 데이터 계산
- 차트를 이용한 재고 현황 시각화
- Excel 파일 가져오기 및 내보내기
- SpreadJS 파일(`.sjs`)을 이용한 대시보드 저장 및 로드

## 샘플 파일

| 파일 | 설명 |
| --- | --- |
| `재고 관리 대시보드.xlsx` | 재고 관리 대시보드 Excel 템플릿 |
| `재고 관리 대시보드.sjs` | SpreadJS에서 사용하는 재고 관리 대시보드 파일 |
| `샘플코드` | SpreadJS를 이용하여 대시보드를 구현하는 JavaScript 샘플 코드 |

## SpreadJS란?

**SpreadJS**는 웹 애플리케이션에서 Excel과 유사한 스프레드시트 기능을 구현할 수 있는 JavaScript 스프레드시트 컴포넌트입니다.

셀 편집, 수식, 차트, 테이블, 조건부 서식, Excel 파일 가져오기/내보내기 등 다양한 스프레드시트 기능을 제공하며, 웹 기반 업무 시스템에서 Excel 형태의 화면이나 대시보드를 구현하는 데 사용할 수 있습니다.

재고 관리뿐만 아니라 다음과 같은 업무 시스템을 구현하는 데 활용할 수 있습니다.

- 재고 관리
- 입출고 관리
- 제품 및 상품 관리
- 물류 관리
- 공급망 관리
- 재고 현황 대시보드
- Excel 기반 업무 시스템의 웹 전환

## 재고 관리 대시보드

이 샘플은 기존 Excel 기반의 재고 관리 업무를 **SpreadJS 기반 웹 스프레드시트 대시보드**로 구현하는 방법을 보여줍니다.

기존 Excel에서 관리하던 제품별 재고 데이터를 웹 애플리케이션에서 조회하고 관리할 수 있으며, 스프레드시트와 차트를 활용하여 현재 재고 현황을 시각적으로 확인할 수 있습니다.

이를 통해 기존 Excel 기반의 재고 관리 업무를 웹 기반 시스템으로 전환하거나, ERP 및 물류 관리 시스템에 Excel과 유사한 재고 관리 기능을 추가할 수 있습니다.
